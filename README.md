# Plan Navigator Pro

Crée le projet Lovable à partir du dépôt GitHub https://github.com/Francois-Cossard/fireseal-tracker-pro et commence par améliorer la prévisualisation du pdf, ainsi que le zoom, qui n'est pas très ergonomique, on ne peut pas circuler simplement sur le plan. Ajouter un raccourci pour les outils "Sélection", "Ajouter" et "Main". Également, ne pas changer d'outil une fois un repère placé. Enfin, ajoute une légende avec les couleurs et entreprises associées qui peut être déplacée sur le plan. Propose également des axes d'amélioration pour le projet.

This project was built with [Lovable](https://lovable.dev).
